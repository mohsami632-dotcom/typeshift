# Example 01: TypeScript to JSON Schema

This example demonstrates compiling static TypeScript interfaces into a valid Draft-07 JSON Schema.

## Files

- [`user.ts`](./user.ts) — Source TypeScript interface with primitive types, optionals, enums, arrays, and records.
- [`user.schema.json`](./user.schema.json) — Expected output JSON Schema generated by `typeshift`.

## Run This Example

```bash
# Using global CLI or local build:
npx @mohsami/typeshift convert user.ts --to json-schema -o user.schema.json
```

## What This Demonstrates

1. **Deterministic Output**: Property definitions are sorted alphabetically (`age`, `email`, `id`, `metadata`, `name`, `role`, `tags`), ensuring clean git diffs.
2. **Type Mapping**:
   - `string`, `number` map to corresponding JSON Schema primitive types.
   - `role: 'admin' | 'member' | 'guest'` maps to `{ "enum": ["admin", "member", "guest"] }`.
   - `metadata?: Record<string, string>` maps to an object schema with `additionalProperties: { type: "string" }`.
   - Optional properties (marked with `?`) are omitted from the `required` array.
3. **Zero Information Loss**: Since JSON Schema can express all static structural constraints present in TypeScript interfaces, 0 diagnostics are emitted.
